# Security policy

Version 1.0.x is the initial security-support scope. No fixed response deadline is guaranteed.

Report vulnerabilities confidentially using [GitHub Private Vulnerability Reporting](https://github.com/Suedehead84/LMU-Setup-Manager/security/advisories/new): Security → Advisories → Report a vulnerability. The feature is enabled and verified through GitHub's API. Suedehead84 confirmed regular monitoring; repository notifications are enabled. An independent reporter-to-maintainer notification delivery test has not been performed.

Include affected version, impact and minimal reproduction with synthetic data. Do not post security details in public issues or attach databases, raw game recordings, pairing links, credentials or personal logs. Coordinate remediation and disclosure within the private report. No unverified email address is advertised.

See [Security and privacy](docs/SECURITY.md) for storage, authentication and unencrypted trusted-LAN limitations.

# ABI evidence used by automated tests

14200-layout.tsv records the compiler-verified sizes, offsets and scalar types.
14200-headers.sha256.json identifies the original installed headers by filename/hash.
No official SDK header is redistributed. Install/access the game's own SDK locally
when independently repeating a compiler probe; use your own installation path.
Historical private probe records containing machine-specific paths are excluded
from the public source snapshot. Synthetic fixtures use C:\LMU as a neutral placeholder,
not an actual user's installation. Interface/fixture redistribution rights remain
part of the final rights review; no SDK license is granted by the project's MIT.

# Voluntary support / Freiwillige Unterstützung

LMU Setup Manager is free and open source. If you enjoy the project, you can
support its development voluntarily. No verified funding account exists yet;
there are no active donation links, required payments, feature restrictions or
promised support entitlements.

To activate later: create/verify the owner's real provider account separately;
confirm its exact identifier and destination. Then add the verified identifier
under github or buy_me_a_coffee in .github/FUNDING.yml and review the resulting
button before public release. The current file contains comments only, so no
placeholder account is advertised. Do not substitute a Git username automatically.

[Official GitHub configuration](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).
